# SSH-Key Based Authentication Setup Configuration

| Step   | Action                                     | Command / File                                                                                                                                                           | Purpose                                                           |
| ------ | ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------- |
| **1️** | Generate SSH key pair                      | `ssh-keygen -t ed25519 -C "your.email@example.com"`                                                                                                                      | Create a private and public key on your local machine.            |
| **2️** | Copy public key to remote server           | `ssh-copy-id -i ~/.ssh/id_ed25519.pub user@remote-server`                                                                                                                | Install your public key on the remote server for key-based login. |
| **3️** | (Alternative manual copy)                  | `bash<br>cat ~/.ssh/id_ed25519.pub \| ssh user@remote-server "mkdir -p ~/.ssh && chmod 700 ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys"` | Manually append your public key if `ssh-copy-id` is unavailable.  |
| **4️** | Test SSH connection                        | `ssh user@remote-server`                                                                                                                                                 | Verify that you can log in without a password.                    |
| **5️** | (Optional) Disable password authentication | Edit `/etc/ssh/sshd_config` → `PasswordAuthentication no`                                                                                                                | Increase security by allowing only key-based login.               |
| **6️** | Restart SSH service                        | `sudo systemctl restart sshd`                                                                                                                                            | Apply SSH configuration changes.                                  |
