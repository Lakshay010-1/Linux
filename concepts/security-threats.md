# Security Threats Types

| No. | Threat Type                              | Description                                                              | Example / Effect                                   |
| :-: | ---------------------------------------- | ------------------------------------------------------------------------ | -------------------------------------------------- |
|  1  | **Malware**                              | General term for malicious software designed to harm or exploit systems. | Includes viruses, worms, trojans, ransomware, etc. |
|  2  | **Virus**                                | Attaches to files and spreads when infected files are executed.          | Corrupts files, deletes data, slows systems.       |
|  3  | **Worm**                                 | Self-replicating malware that spreads automatically across networks.     | Network slowdowns, DoS, data theft.                |
|  4  | **Trojan Horse**                         | Appears legitimate but hides malicious actions.                          | Keyloggers, backdoors, data theft.                 |
|  5  | **Spyware**                              | Monitors user activity and sends data to attackers.                      | Captures keystrokes, passwords, browsing data.     |
|  6  | **Adware**                               | Displays unwanted ads; may track user behavior for profit.               | Slows system, collects personal data.              |
|  7  | **Ransomware**                           | Encrypts files and demands payment to unlock them.                       | Locks out users, demands ransom.                   |
|  8  | **Rootkit**                              | Hides malicious activity from detection tools.                           | Grants invisible root/admin control.               |
|  9  | **Keylogger**                            | Records user keystrokes.                                                 | Steals credentials or payment info.                |
| 10  | **Botnet**                               | Group of infected systems controlled by an attacker.                     | Used for DDoS or mass spam campaigns.              |
| 11  | **DDoS (Distributed Denial of Service)** | Floods servers with traffic to make them unavailable.                    | Website/service downtime.                          |
| 12  | **Phishing**                             | Fake emails/websites trick users into revealing info.                    | Credential theft, bank fraud.                      |
| 13  | **Spoofing**                             | Impersonating another user/system (IP, email, DNS).                      | Redirects data, steals information.                |
| 14  | **Man-in-the-Middle (MitM)**             | Intercepts and alters communication between two parties.                 | Eavesdropping, data manipulation.                  |
| 15  | **SQL Injection**                        | Inserts malicious SQL commands into web inputs.                          | Extracts or modifies database data.                |
| 16  | **Cross-Site Scripting (XSS)**           | Injects malicious scripts into trusted websites.                         | Steals cookies, sessions, user data.               |
| 17  | **Brute Force Attack**                   | Tries all password combinations until successful.                        | Gains unauthorized access.                         |
| 18  | **Zero-Day Exploit**                     | Exploits an unknown, unpatched vulnerability.                            | High-risk; no patch available.                     |
| 19  | **Social Engineering**                   | Manipulates people to reveal confidential info.                          | Pretending to be IT/admin staff.                   |
| 20  | **Insider Threat**                       | Data theft or damage from within the organization.                       | Employee leaks or sabotage.                        |

---

| Category                   | Examples                                          | Typical Target / Impact                     |
| -------------------------- | ------------------------------------------------- | ------------------------------------------- |
| **Network Attacks**        | DDoS, MitM, Spoofing, Sniffing                    | Disrupt or intercept network communications |
| **Malware Attacks**        | Virus, Worm, Trojan, Ransomware, Rootkit, Spyware | Infect or control systems                   |
| **Application Attacks**    | SQL Injection, XSS, Buffer Overflow               | Exploit software vulnerabilities            |
| **Human / Social Attacks** | Phishing, Social Engineering, Insider Threat      | Exploit user behavior and trust             |
| **System Exploits**        | Zero-Day, Privilege Escalation, Keyloggers        | Abuse OS or software flaws for control      |
