# Linux Boot Process

- When a computer starts, the hardware and BIOS/UEFI complete their part (that’s the computer boot process).<br/>Once control is passed to the bootloader (like GRUB) — the Linux boot process begins.

- | Step No. | Stage / Component                          | Purpose / Function               | Description                                                                                                                         | Output / Result                            |
  | -------- | ------------------------------------------ | -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------ |
  | **1**    | **`Bootloader (GRUB2 / LILO)`**            | Loads kernel and initramfs.      | BIOS/UEFI executes GRUB, which loads the Linux kernel and initramfs from `/boot` into memory and passes boot parameters.            | Kernel and initramfs loaded into RAM.      |
  | **2**    | **`Kernel Initialization (vmlinuz)`**      | Initialize system hardware.      | Kernel decompresses, initializes CPU, memory, and drivers, and mounts **initramfs** as a temporary filesystem.                      | Kernel active; temporary filesystem ready. |
  | **3**    | **`initramfs / initrd Execution`**         | Mount real root filesystem.      | initramfs detects disks and mounts the real root (`/`) partition, then switches to it using `switch_root`.                          | Real root filesystem mounted.              |
  | **4**    | **`Start Init Process (systemd – PID 1)`** | Start user-space initialization. | Kernel starts **systemd**, the first process in user-space, which manages all other processes.                                      | systemd running as PID 1.                  |
  | **5**    | **`systemd Initialization`**               | Start system services.           | systemd mounts filesystems, starts core services (**udev**, network, logging), and reads configuration from `/etc/systemd/system/`. | System services started.                   |
  | **6**    | **`Systemd Targets (Runlevels)`**          | Define system boot mode.         | systemd activates a target such as:<br>• `multi-user.target` (CLI)<br>• `graphical.target` (GUI).                                   | System enters target environment.          |
  | **7**    | **`Login Services Start`**                 | Provide user login access.       | systemd starts **getty** (CLI) or **Display Manager** (GUI) and initializes daemons.                                                | Login screen or prompt displayed.          |
  | **8**    | **`User Authentication`**                  | Verify credentials.              | User logs in; **PAM** validates username and password.                                                                              | User authenticated.                        |
  | **9**    | **`User Session Initialization`**          | Load user environment.           | Shell or desktop environment starts; user startup files (`.bashrc`, `.profile`) are loaded.                                         | System ready for use                       |
